The scanner configuration for your LANytic instance.

Scanner

Run ip -br -4 addr on the Linux Docker host, outside the container. Choose the interface with the IPv4 address of the LAN you want to scan, e.g. enp3s0 or br0. Do not choose lo or docker0.

Saved in the persistent data volume. Changes take effect immediately; no restart required. Settings can be changed after the current scan finishes.

How devices are discovered

ARP discovers IPv4 devices in the local network segment. Devices keep their descriptions and Known status as long as their MAC address and interface stay the same. Offline means no response was received during the last successful scan.

For additional network segments, configure the corresponding host interfaces above. Randomized MAC addresses can appear as new devices.
